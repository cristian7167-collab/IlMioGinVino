✨ Riconoscimento con IA

Configura una volta il tuo servizio privato. La chiave OpenAI si salva sul Cloudflare Worker, mai nel sito o qui. Il codice d’accesso serve a proteggere le richieste.

Servizio IA non configurato.

📱 Installa su Android

Dopo aver pubblicato questa app nella cartella vino-distillati su GitHub Pages (HTTPS), aprila con Chrome e premi il pulsante qui sotto. Le vecchie app rimarranno indipendenti.

Da un file HTML locale l'installazione come app e il GPS possono essere limitati. Usa l'indirizzo HTTPS pubblicato.

Come funziona il salvataggio?

I dati vengono salvati in IndexedDB del browser, oppure in memoria locale se IndexedDB non è disponibile. L'archivio è distinto da quello delle app precedenti. Su Android, per geolocalizzazione e affidabilità del salvataggio è preferibile aprire il file da un indirizzo HTTPS. Se cancelli i dati del browser, perdi le schede non esportate.

IA: l’analisi delle etichette richiede un servizio Cloudflare Worker configurato con una chiave API mantenuta segreta. Le foto vengono elaborate da un fornitore IA esterno solo quando chiedi l’analisi. L’app non invia automaticamente GPS o archivio.
