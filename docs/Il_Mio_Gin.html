I TUOI DATI

Conserva i tuoi ricordi.

Backup della collezione

Le schede e le fotografie restano nel browser di questo dispositivo. Esporta un backup ogni tanto, soprattutto prima di cambiare telefono.

Posizione delle fotografie

Quando scatti una foto puoi autorizzare il GPS. Per le immagini importate cerco le coordinate nei metadati EXIF, quando disponibili. Regione di origine e luogo dello scatto sono due dati separati.

La tua privacy

Nessun account richiesto. Le fotografie, le note e le coordinate non vengono caricate sul nostro server: sono conservate localmente nel browser. Se cancelli i dati del sito potresti perdere la collezione; utilizza il backup.
